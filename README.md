# WOW-MARKET

Собственный мониторинг аукциона **WoW Forever · EU · Альянс** с расчётом выгодных крафтов по вашим профессиям.

Сайт: `https://<ваш-ник>.github.io/WOW-MARKET/`

## Как это работает

- **Каждый час** GitHub Actions запускает `scripts/fetch.mjs`: берёт снимок аукциона из Blizzard API, считает минимальную/рыночную цену, объём и историю (72 часа по часам, 60 дней по дням) и публикует всё на GitHub Pages.
- **Аддон `WolfichMarket`** в игре записывает ваши профессии, выученные рецепты, материалы и цены торговцев. Команда `/wm` выдаёт текст, который вставляется на сайте во вкладке «Скан».
- **Сайт** (`index.html`) — вкладки «Рынок», «Крафт», «Сигналы», «Покупки», «Скан». Ваши настройки и скан хранятся только в вашем браузере.

## Настройка (один раз)

1. **Settings → Secrets and variables → Actions → New repository secret**:
   `BLIZZARD_CLIENT_ID` и `BLIZZARD_CLIENT_SECRET` (с develop.battle.net).
2. **Settings → Pages → Source: GitHub Actions**.
3. **Actions → «Обновление цен аукциона» → Run workflow**. Через 2–3 минуты сайт заработает.

Собираются **все аукционы Альянса** (в API их несколько, по одному на мир) — на сайте выбирается нужный.
Необязательные переменные (**Variables**): `FACTION` (`alliance` / `horde` / `neutral`), `HOUSE_ID` — номера аукционов через запятую.

## Аддон на CurseForge

1. Создайте проект на authors.curseforge.com (World of Warcraft → Addon, имя WolfichMarket).
2. Там же создайте API-токен.
3. Секреты репозитория: `CF_API_KEY` (токен) и `CF_PROJECT_ID` (номер проекта).
4. Новая версия выходит при пуше тега `vX.Y.Z` (или Actions → «Выпуск аддона» → Run workflow): архив попадает в релизы GitHub и на CurseForge.
   Если версия игры подобралась неверно — задайте переменную `CF_GAME_VERSION`.

## Что значат цены

- **Мин.** — самый дешёвый лот за штуку.
- **Рыночная** — средняя по самым дешёвым 15% всего объёма: так один «демпинговый» лот не искажает цену.
- **Прибыль крафта** = рыночная цена × среднее число предметов × (1 − 5% комиссии) − материалы по самой дешёвой цене (торговец или аукцион).
