# Wolfich QuestDB · WoW Forever

База заданий для Альянса, Орды и общих квестов. Форматы: SQLite, CSV, HTML.

**Источники:**
- [QuestieDB / TrinityCore Forever / NorgannonDB](https://github.com/tyler3497/forever-quests) — версии данных 1.3.0, 4 630 квестов в основной выгрузке.
- [ForeverDB](https://foreverdb.net) — независимые данные 3 862 квестов с именами NPC и координатами, где имеются. **Data from ForeverDB.net**.

**Ограничения данных:** это открытые датасеты, не подтверждённая полная база действующего игрового сервера. Русские названия квестов не включены в исходные файлы, поэтому названия хранятся на английском. Выгрузка Questie хранит коэффициенты наград опыта/денег, а не итоговые суммы — не считайте их готовыми значениями XP и меди. Координаты из ForeverDB могут быть подтверждены игроками Forever либо перенесены из Classic; источник каждого значения сохранён.

## Готовые файлы

Если сборка успешно опубликована, файлы находятся в папке `dist/`:

- `wow_forever_quests.sqlite` — основная база SQLite (включает сырой JSON обеих выгрузок).
- `quests_browser.html` — автономный HTML-поиск; открой двойным щелчком, без сервера.
- `quests.csv` — список квестов для Excel.
- `locations.csv` — NPC/объекты, координаты, происхождение координат.
- `rewards.csv` — награды: предметы, репутация, коэффициенты XP/денег.
- `chains.csv` — связи квестовых цепочек.
- `coverage.json` — статистика покрытия и пропусков.

## Как собрать/обновить самостоятельно

Требуется Python 3.9+ и подключение к интернету:

```powershell
py -3 build_db.py --out dist
```

Первый запуск скачивает публичные JSON-файлы в `.source-cache/` и создаёт базу. Повторное построение из уже скачанных данных без интернета:

```powershell
py -3 build_db.py --out dist --offline
```

## SQLite-таблицы

`quests` — идентификаторы, уровни, фракции, зоны, флаги, полные исходные JSON; `actors` — начальные/конечные NPC/предметы/объекты и координаты; `objectives` — цели; `rewards` — все категории наград из основного датасета; `quest_links` — предшествующие/следующие задания и исключающие квесты; `zones` — зоны, `meta` — происхождение. `quest_search` — полнотекстовый поиск FTS5 (если доступен).

Пример SQL:

```sql
SELECT id,title,quest_level,zone_name FROM quests
WHERE faction IN ('Альянс','Обе') AND min_level <= 20
ORDER BY quest_level,id;
```

Лицензия исходных данных и дополнительная информация — в соответствующих исходных репозиториях. Этот сборщик не содержит проприетарных текстов заданий из игрового клиента.
