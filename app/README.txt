WOLFICH Market — программа для Windows
======================================
Мониторинг аукциона WoW Forever (EU, Альянс): цены, выгодные крафты по вашим профессиям,
сигналы о скачках цен и список покупок. Сканирует аукцион по вашему расписанию.

Установка (один раз)
1. Распакуйте архив в любую папку (например, C:\WOLFICH-Market). Запускать прямо из архива нельзя.
2. Запустите SETUP.bat — он скачает Electron с GitHub (около 110 МБ), соберёт WOLFICH-Market.exe
   и положит ярлык «WOLFICH Market» на рабочий стол.
   Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».

Обновление: распакуйте новый архив поверх старой папки (с заменой файлов) и запустите SETUP.bat —
скачивать Electron заново не придётся. Настройки и история цен сохранятся.

Первый запуск — вкладка «Программа»
• Источник данных:
  – «Сайт WOW-MARKET» — работает сразу, данные обновляются раз в час;
  – «Свой ключ Blizzard» — программа сама сканирует аукцион с вашим интервалом.
    Ключ: develop.battle.net → API Access → Create Client (Client ID и Client Secret).
    Секрет хранится на вашем компьютере в зашифрованном виде.
• Интервал сканирования: от 5 минут. Blizzard обновляет снимок аукциона примерно раз в час —
  если снимок не изменился, программа не качает его заново.
• Папка игры находится сама; «Установить аддон» кладёт WolfichMarket в Interface\AddOns.
• Скан профессий подхватывается сам: откройте профессии в игре и наберите /reload (или выйдите из игры).

Программа сворачивается в трей (значок у часов) и продолжает сканировать.
Уведомления: когда цена из «Покупок» падает до цели и при скачках цен на ваши материалы.
